# Receipts

`r01`–`r37` are synthetic, generated by `python scripts/make_receipts.py` (23 clean, 14 with planted
violations). To add real receipts, drop the file here (PDF, JPG/PNG, or .eml) and add a row to
`bench/labels.csv`:

    file,expected_decision,expected_category,violations
    my_lunch.jpg,approve,meals,

`violations` is a `;`-separated list of: over_limit, non_reimbursable, duplicate, missing_info,
weekend, fake_vendor. Decision rule: duplicate or non_reimbursable -> reject; any other violation
-> flag; none -> approve.

Note: rerunning `make_receipts.py` rewrites `labels.csv`, so add your real rows after generating.
